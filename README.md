# derzhava-look

Оформление Claude Code «Державный» для работы над игрой «Держава»: тёплая бумага в светлой теме и тёмно-синяя ночь в тёмной, акцент синий, тёплый цвет золотой. Над полем ввода есть полоса, где видно, насколько заполнен контекст, и кнопка «Очистить контекст». Первое нажатие спрашивает «Точно очистить?», второе в течение пяти секунд запускает /clear так же, как если бы его набрали вручную.

Светлая тема — сине-жёлтый пляж (синее небо и море над жёлтым песком), тёмная — красно-чёрный (красное закатное небо над чёрным морем и песком). Движение медленное: волны, облака, блики, пальма, чайки, звёзды.

## Установка

В Claude Code (терминал), в папке проекта:

```
/plugin install derzhava-look --marketplace Somgurung40/derzhava-look
```

Затем `y`, чтобы добавить маркетплейс, и выбрать область (scope).
